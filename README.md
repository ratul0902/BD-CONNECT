# BD Connect — Latest Android Release

Android VPN client built with `sing-box` (`Libbox`) for fast and stable connections.

### What's Included
- Background tunnel state sync & live connection status
- Subscription profile import, updates, quota/expiry display, and node latency check
- Light & Dark theme support with in-app Terms & Conditions

### Installation
1. If you already have an older version installed, check whether your signing key matches; otherwise uninstall the old build first.
2. Download the attached `.apk` file from **Assets** below.
3. Open the downloaded APK, allow install from browser/file manager if prompted, and tap **Install**.
4. Open **BD Connect**, add your subscription/profile, choose a server, and tap **Connect**.
